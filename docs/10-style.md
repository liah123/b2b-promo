# 스타일 가이드 — Stamp Up

버전: v1.0 (작성일: 2026-08-20)
근거 문서: 참고 스크린샷 3장(협동 미션 화면, 회원가입 화면 x2), `docs/3-PRD.md`(v1.5, React19 반응형 웹), `docs/7-wireframe.md`(v1.4, 화면별 레이아웃)

> 참고 스크린샷의 **모양(둥근 코너/필 형태 UI)과 레이아웃 구조**는 그대로 채용하되, **메인 컬러는 브라운/오렌지 대신 그린 계열로 교체**한다. 다크모드·접근성 세부 대응은 `3-PRD.md` 4장 기준대로 이번 범위에서 다루지 않는다(오버엔지니어링 방지).

---

## 1. 디자인 컨셉

- **톤앤매너**: 친근하고 동글동글한 "스탬프 카드" 감성. 각진 요소를 최소화하고 원/필(pill) 형태를 적극 사용한다.
- **메인 컬러**: 그린 (재료·적립·성장의 이미지와 브랜드명 "Stamp Up"에 부합).
- **배경**: 미션/스탬프 관련 메인 화면은 연한 라임그린 → 그린 그라디언트 배경을 사용해 생동감을 준다. 폼·목록 등 정보 위주 화면은 화이트 배경 + 그린 포인트로 가독성을 우선한다.

| 토큰 | HEX | 용도 |
|---|---|---|

## 3. Shape — 둥근 형태 시스템

참고 스크린샷의 핵심 특징인 "각 없는 둥근 UI"를 토큰화한다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `radius-xs` | 8px | 작은 태그/칩(`[필수]` 등) |
| `radius-sm` | 12px | 인풋 필드, 보조 버튼, 체크박스 |
| `radius-md` | 16px | 리스트 아이템, 중간 카드 |
| `radius-lg` | 24px | 메인 카드(미션 카드 등), 바텀시트 |
| `radius-full` | 9999px | 메인/CTA 버튼, 상태 배지, 아바타, 일차 선택 칩(day-chip) |

- 카드·버튼·인풋 등 UI 요소는 예외 없이 위 토큰 중 하나를 사용한다. 임의의 각진(0px) 모서리는 사용하지 않는다.
- 아바타, 카운트 배지, 진행 상태 배지, 메인 CTA 버튼은 항상 `radius-full`(완전한 원/필 형태)을 사용한다 — 참고 스크린샷의 동그란 쉐잎 컨셉 핵심.

## 4. Typography

- **폰트**: Pretendard (한글 가독성·둥근 느낌 좋은 오픈소스 폰트), fallback `-apple-system, system-ui, sans-serif`.
- 별도 커스텀 폰트 로딩/서브셋팅 최적화는 이번 범위에서 다루지 않는다(YAGNI — 필요해지면 그때 추가).

| 스타일 | 크기/굵기 | 용도 |
|---|---|---|
| Display | 22px / Bold(700) | 화면 상단 타이틀(예: "협동 미션") |
| Title | 17px / Bold(700) | 카드 제목("No 커피, No 편의점") |
| Body | 15px / Regular(400)~Medium(500) | 본문, 폼 라벨 |
| Caption | 13px / Regular(400) | 보조 설명, 타임스탬프, placeholder |
| Button | 16px / SemiBold(600) | 버튼 텍스트 |

- 본문 텍스트 컬러는 `neutral-900`, 보조 텍스트는 `neutral-600`/`neutral-400`을 사용한다.

## 5. 컴포넌트 스타일

### 5.1 버튼

| 종류 | 배경 | 텍스트 | 모양 | 예시 |
|---|---|---|---|---|
| Primary | `green-500` (pressed: `green-600`) | 흰색 Bold | `radius-full`, 풀와이드 | "회원가입 완료", "쿠폰 받기" |
| Secondary | `neutral-800`(다크) 또는 `green-500` 아웃라인 | 흰색 / `green-500` | `radius-sm` | "인증번호 요청", "자세히 보기" |
| Disabled | `neutral-100` | `neutral-400` | 동일 모양 유지, 색만 대체 | 조건 미충족 버튼 |

- 스크린샷의 다크 브라운 CTA(`자세히 보기`, `인증번호 요청`)는 브랜드 메인 컬러가 그린이므로, 화면당 주요 액션(가장 중요한 CTA)은 **Primary Green**, 보조 액션(정보성 확인, 인증 요청 등)은 다크 뉴트럴(Secondary)로 역할을 나눈다.

### 5.2 인풋 필드

- 배경 `neutral-50`, `radius-sm`, 보더 없음(또는 1px `neutral-200`), placeholder `neutral-400`.
- 포커스 시 보더 `green-500` 1.5px.
- 비활성/읽기전용 필드는 배경을 `neutral-100`으로 낮춰 구분한다(회원가입 화면의 "인증번호 입력" 필드처럼 활성화 전 상태를 시각적으로 구분).

### 5.3 카드

- 배경 `neutral-0`(흰색), `radius-lg`, 옅은 그림자(`0 2px 12px rgba(0,0,0,0.06)`), 내부 패딩 16~20px.
- 카드 내 성공/실패 금액처럼 대비되는 정보는 `success`/`danger` 컬러로 굵게 표시한다.

### 5.4 상태 배지(Status Pill)

- 배경 `green-100`, 텍스트 `green-700`, `radius-full`, 좌우 패딩 10px — 예: "진행중".
- 비활성/종료 상태는 `neutral-100` 배경 + `neutral-600` 텍스트로 대체한다.

### 5.5 일차/단계 선택 칩(day-chip)

- 선택됨: `neutral-800`(다크) 배경, 흰색 아이콘/텍스트, `radius-full`.
- 미선택: `neutral-0` 배경, `neutral-400` 아이콘/텍스트, `radius-full`, 옅은 보더.

### 5.6 아바타 & 카운트 배지

- 아바타: `radius-full`, 배경은 톤온톤 파스텔(피치/옐로우 등 자유), 이모지·아이콘 중앙 배치.
- 카운트 배지: 아바타 우하단에 겹쳐 배치, 배경 `green-500`, 흰색 숫자, `radius-full`, 크기 아바타의 1/3 이하.

### 5.7 체크박스

- 미체크: `radius-sm`, 1px `neutral-200` 보더, 흰 배경.
- 체크됨: `green-500` 배경, 흰색 체크 아이콘.

## 6. 아이콘 & 일러스트 톤

- 라인/이모지 혼용 스타일(예: 🦊, 🐟 이모지 아바타), 과도하게 사실적인 일러스트는 지양한다.
- 아이콘 색상은 기본적으로 `neutral-800` 또는 `green-500`만 사용해 컬러 수를 제한한다.
