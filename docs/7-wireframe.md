# 와이어프레임 — YumStamp

버전: v1.4 (작성일: 2026-08-13, v1.3→v1.4: docs 정합성 검토 — 근거 문서 버전 갱신, 4번 화면 적립 요청 버튼 비활성화 조건에 예정(PENDING) 상태 추가(참여 기간 내에만 참여 가능 규칙과 정합))
근거 문서: `docs/1-domain-definition.md` (v1.6), `docs/3-PRD.md` (v1.5, 3장/4장), `docs/4-user-scenari.md` (v1.1), `docs/5-project-principle.md` (v1.1, 6장 프론트엔드 pages 목록)

> 반응형 웹 UI(PRD 4장) 반영: 거래처 담당자(CUSTOMER)가 쓰는 모든 화면은 데스크탑/모바일 두 버전을 함께 표시한다. 데스크탑은 상단 가로 내비게이션 + 다열 그리드/표, 모바일은 상단 [메뉴] 아이콘 내비게이션 + 1열 세로 스크롤 카드로 통일한다. 관리자(ADMIN) 전용 화면은 사무실 데스크탑 사용을 전제로 데스크탑 1개만 표시한다 (PRD 기술제약: 모바일은 반응형 웹으로만 대응, 별도 앱 없음).

## 0. 용어 변경 기준

화면에 보이는 문구(화면명/버튼/라벨/시나리오 서술)는 "게임형 미션/리워드" 톤 대신 "일반 매장 스탬프 적립/쿠폰" 톤을 쓴다. **아래는 화면 표시 문구 매핑이며, 내부 엔티티명·DB/코드 식별자(Mission, MissionParticipation, StampTransaction, Reward, RewardRedemption, ingredientType, recipe, JOINED/COMPLETED, ACTIVE/INACTIVE/PENDING/ENDED, API 라우트 `/missions` `/rewards`, 파일명 `MissionListPage.tsx` 등)는 변경되지 않는다.**

| 기존(게임형 문구) | 변경(스탬프 적립/쿠폰 문구) |
|---|---|
| 미션 | 적립 항목 |
| 미션 목록 | 스탬프 적립 안내 |
| 내 미션 | 적립 진행 현황 |
| 참여하기 | 자세히 보기(목록) / 적립 요청 또는 확인(상세, 정책에 따라) |
| 완료 처리(고객 화면) | 직원 확인 대기 → (관리자가) 확인 처리 |
| 재료/스탬프 재료 | 스탬프 |
| 리워드 | 쿠폰 / 혜택 |
| 교환하기 | 쿠폰 받기 / 혜택 사용하기 |
| 교환 내역 | 쿠폰 사용 내역 |

## 1. 로그인 / 회원가입

### 데스크탑
```
+------------------------------------------+
|              YumStamp                    |
|                                            |
|   [로그인]  [회원가입]  (탭 전환)          |
|                                            |
|   이메일    [_____________________]       |
|   비밀번호  [_____________________]       |
|                                            |
|   회원가입 시에만 추가 입력:                |
|   이름      [_____________________]        |
|                                            |
|            [ 로그인 / 가입하기 ]           |
|                                            |
|   (오류 시) "이미 가입된 이메일입니다" 등   |
+------------------------------------------+
```
(화면 중앙에 고정폭 카드로 배치, 좌우 여백은 배경)

### 모바일
```
+----------------------+
|      YumStamp        |
+----------------------+
| [로그인] [회원가입]   |
|                       |
| 이메일                |
| [_________________]  |
| 비밀번호              |
| [_________________]  |
|                       |
| (회원가입 시)          |
| 이름                  |
| [_________________]  |
|                       |
| [  로그인/가입하기  ]  |
|                       |
| (오류 메시지 영역)     |
+----------------------+
```
(카드가 화면 전체 폭을 채우고 입력란은 세로로 쌓임)

- 이메일/비밀번호 입력 (로그인 공통)
- 회원가입 탭에서는 이름 입력란 추가, 가입 시 role은 자동으로 CUSTOMER
- 이메일 중복 시 오류 메시지 표시 (ADMIN 계정은 회원가입 화면에서 생성하지 않음)
- 로그인 성공 시 access token/refresh token 발급 후 스탬프 홈 화면으로 이동
- 비로그인 상태로 다른 화면 접근 시 이 화면으로 리다이렉트

## 2. 스탬프 홈 (로그인 후 첫 화면)

### 데스크탑
```
+--------------------------------------------------------------+
| YumStamp   [홈][적립 안내][쿠폰/혜택][이용 내역][마이페이지] [로그아웃] |
+--------------------------------------------------------------+
| 안녕하세요, ㅇㅇ님                                              |
|                                                                |
| 보유 스탬프                                                     |
| +--------+ +--------+ +--------+                              |
| | 양파    | | 당근    | | 감자    |                             |
| |  3개   | |  1개   | |  0개   |                              |
| +--------+ +--------+ +--------+                              |
|                                                                |
| 지금 받을 수 있는 혜택                                           |
| +----------------+ +----------------+                         |
| | 카레            | | 김치찌개        |                        |
| | [쿠폰 받기]      | | [쿠폰 받기]      |                        |
| +----------------+ +----------------+                         |
|                                       [ 쿠폰/혜택 전체 보기 > ] |
|                                                                |
| 최근 이용 내역                                                  |
| 08-07 11:00  당근 스탬프 +1 (적립 확인)                          |
| 08-06 09:00  양파 스탬프 -1 (쿠폰 사용)                          |
|                                       [ 이용 내역 전체 보기 > ] |
+--------------------------------------------------------------+
```

### 모바일
```
+----------------------+
| YumStamp      [메뉴]  |
+----------------------+
| 안녕하세요, ㅇㅇ님     |
|                       |
| 보유 스탬프 (가로스크롤)|
| +------+ +------+     |
| | 양파  | | 당근  | >  |
| | 3개  | | 1개  |     |
| +------+ +------+     |
|                       |
| 지금 받을 수 있는 혜택  |
| +-------------------+ |
| | 카레                | |
| | [   쿠폰 받기   ]   | |
| +-------------------+ |
| [ 쿠폰/혜택 전체 보기 ]|
|                       |
| 최근 이용 내역          |
| +-------------------+ |
| |08-07 당근 +1        | |
| |적립 확인            | |
| +-------------------+ |
| [ 이용 내역 전체 보기 ]|
+----------------------+
```

- 로그인 직후 진입하는 첫 화면: 보유 스탬프 요약 + 지금 받을 수 있는 혜택 미리보기 + 최근 이용 내역 미리보기를 한눈에 보여준다
- "쿠폰/혜택 전체 보기"는 6번 화면(쿠폰/혜택 목록)으로, "이용 내역 전체 보기"는 5번 화면(스탬프 및 이용 내역)으로 이동
- 새로운 데이터나 상태를 만들지 않는 요약 화면이며, 표시 데이터는 기존 보유 스탬프/쿠폰·혜택 목록/스탬프 이력을 그대로 재사용

## 5. 적립 진행 현황 (참여중/완료 구분)

### 데스크탑
```
+--------------------------------------------------------------+
| YumStamp   [홈][적립 안내][쿠폰/혜택][이용 내역][마이페이지] [로그아웃] |
+--------------------------------------------------------------+
| 적립 진행 현황                                                  |
|                                                                |
| [직원 확인 대기] ---------------------------------------------  |
| 적립 항목명 A   요청일 08-05                     [확인 요청]    |
| 적립 항목명 B   요청일 08-07                     [확인 요청]    |
|                                                                |
| [적립 완료]  ---------------------------------------------      |
| 적립 항목명 C   완료일 08-03   지급스탬프: 양파 2                 |
+--------------------------------------------------------------+
```

### 모바일
```
+----------------------+
| YumStamp      [메뉴]  |
+----------------------+
| 적립 진행 현황          |
|                       |
| [직원 확인 대기]        |
| +-------------------+ |
| | 적립 항목명 A        | |
| | 요청일 08-05        | |
| | [  확인 요청  ]     | |
| +-------------------+ |
|                       |
| [적립 완료]             |
| +-------------------+ |
| | 적립 항목명 C        | |
| | 완료일 08-03        | |
| | 지급스탬프: 양파 2   | |
| +-------------------+ |
+----------------------+
```

- 참여중(JOINED) 항목은 "직원 확인 대기", 완료(COMPLETED) 항목은 "적립 완료" 섹션으로 구분해 표시
- 직원 확인 대기 항목에는 테스트용 "확인 요청" 버튼 표시 → 클릭 시 적립 조건 충족 처리 및 스탬프 지급 (내부적으로는 기존 완료 처리 로직과 동일)
- 적립 완료 항목에는 완료일, 지급받은 스탬프 종류/수량 표시
- 이미 완료된 항목은 재확인 버튼이 없거나 눌러도 재지급되지 않음

## 6. 스탬프 및 이용 내역 (스탬프 종류별 보유량 + 이력)

### 데스크탑
```
+--------------------------------------------------------------+
| YumStamp   [홈][적립 안내][쿠폰/혜택][이용 내역][마이페이지] [로그아웃] |
+--------------------------------------------------------------+
| 스탬프 및 이용 내역                                              |
|                                                                |
| 스탬프 종류별 보유량                                             |
| +--------+ +--------+ +--------+                              |
| | 양파    | | 당근    | | 감자    |                             |
| |  3개   | |  1개   | |  0개   |                              |
| +--------+ +--------+ +--------+                              |
|                                                                |
| 이용 내역                                                       |
| 일시        스탬프  구분   수량   사유                            |

```

### 모바일
```
+----------------------+
| YumStamp      [메뉴]  |
+----------------------+
| 스탬프 및 이용 내역     |
|                       |
| 스탬프 종류별 보유량(가로스크롤)|
| +------+ +------+     |
| | 양파  | | 당근  | >  |
| | 3개  | | 1개  |     |
| +------+ +------+     |
|                       |
| 이용 내역               |
| +-------------------+ |
| |08-05 양파 +2       | |
| |적립 확인            | |
| +-------------------+ |
| |08-06 양파 -1       | |
```

- 상단: 스탬프 종류별 현재 보유 개수 카드 (모바일은 카드가 많아지면 가로 스크롤, 이력은 표 대신 카드 리스트로 대체)
- 하단: 스탬프 종류별 적립/차감 이력 목록 (일시, 스탬프 종류, 구분(적립/차감), 수량, 사유)
- 보유량은 스탬프 종류별로 각각 표시 (총합으로 합산하지 않음)

- 각 카드에 혜택명, 필요 스탬프(종류·수량), 받을 수 있는지 여부(보유 스탬프 기준) 표시
- 받을 수 있을 때만 "쿠폰 받기" 버튼 활성화, 부족 시 비활성화 표시
- 비활성(INACTIVE) 혜택은 목록에서 제외되거나 비활성 표시로 노출(신규로 받기 불가)

## 10. (관리자) 적립 항목 관리 (목록/등록/수정)

```
+--------------------------------------------------------------+
| YumStamp [관리자]  [적립 항목 관리][혜택 관리][마이페이지] [로그아웃] |
+--------------------------------------------------------------+
| 적립 항목 관리                                [ + 적립 항목 등록 ]|
|                                                                |
| 항목명   상태     기간                지급스탬프/수량   관리       |
| 항목 A   [진행중] 08-01~08-20        양파 2         [수정][종료]|
| 항목 B   [예정]   08-22~08-30        감자 1         [수정]      |
| 항목 C   [종료]   07-01~07-15        당근 1         [수정]      |
+--------------------------------------------------------------+
| (등록/수정 시 하단 또는 별도 폼)                                |
| 항목명        [_____________________]                         |
| 설명          [_____________________]                         |
| 기간          시작[______] 종료[______]                        |
| 적립 조건     [_____________________]                         |
| 지급 스탬프 종류 [양파 v]   지급 수량 [__2__]                    |
|                              [ 저장 ]                          |
+--------------------------------------------------------------+
```

- 목록: 항목명, 상태(예정/진행중/종료), 기간, 지급 스탬프 종류/수량, 관리(수정/종료) 표시
- "적립 항목 등록" 클릭 시 등록 폼 노출(항목명/설명/기간/적립 조건/지급 스탬프 종류/지급 수량 입력)
- 상태는 기간 기준 자동 계산이 기본, 진행중 항목에 한해 수동 "종료" 처리 버튼 제공(예외 처리)
- 항목별 참여자 목록에서 **적립 확인 처리**(고객 화면의 확인 요청과 동일 로직)를 수행할 수 있는 진입점 제공 — 별도의 승인/거절 상태는 두지 않는다(참여중/완료 2가지 상태만 사용)

## 11. (관리자) 혜택 관리 (목록/등록/수정)

```
+--------------------------------------------------------------+
| YumStamp [관리자]  [적립 항목 관리][혜택 관리][마이페이지] [로그아웃] |
+--------------------------------------------------------------+
| 혜택 관리                                     [ + 혜택 등록 ]  |
|                                                                |
| 혜택명    필요 스탬프              상태       관리                |
| 카레      양파2, 당근1           [활성]     [수정][비활성화]     |
| 된장찌개  양파1, 감자2           [활성]     [수정][비활성화]     |
| 김치찌개  당근3                  [비활성]   [수정][활성화]       |
+--------------------------------------------------------------+
| (등록/수정 시 하단 또는 별도 폼)                                |
| 혜택명   [_____________________]                               |
| 설명     [_____________________]                               |
| 필요 스탬프 종류[양파 v] 수량[_2_]  [+ 스탬프 추가]              |
|          종류[당근 v] 수량[_1_]                                 |
|                              [ 저장 ]                          |
+--------------------------------------------------------------+
```

- 목록: 혜택명, 필요 스탬프(종류/수량 목록), 상태(활성/비활성), 관리(수정/상태전환) 표시
- "혜택 등록" 클릭 시 등록 폼 노출(혜택명/설명/필요 스탬프 목록 입력, 스탬프 종류 행 추가 가능)
- 상태 전환 버튼으로 활성 ↔ 비활성 전환(비활성 시 신규으로 받기 불가)
