- 테스트 대상: 로컬 dev 서버 (`http://localhost:5173` 프론트엔드 + `http://localhost:3000` 백엔드)
- 테스트 방식: Playwright MCP를 이용한 실제 브라우저 기반 회귀 테스트
- 테스트 일자: 2026-08-21
- 목적: 최근 반영한 UI 개선사항(헤더 여백, 카드형 섹션, 버튼형 링크, 미션/리워드 명칭 변경)이 실제 화면에 정상 반영되고 기존 핵심 플로우가 깨지지 않았는지 확인

## 주요 확인 사항

- `.app-main` 상단 패딩 추가로 헤더와 본문 사이 여백이 정상적으로 생김
- 홈 화면 3개 섹션(보유 스탬프/혜택/이용내역) 모두 카드 박스(`page-section`) 안에 렌더링되며, 제목 우측에 버튼형 "전체보기 ›" 링크가 표시됨
- 관리자/고객 화면 전반에서 미션명이 "행사 양파 구매하기", "신선 당근 구매하기", "정기구매 3회 달성하기" 등 행위 중심 문구로, 리워드명이 "카레처럼 든든한 1,000원 할인 쿠폰", "김치찌개처럼 얼큰한 무료배송 쿠폰"처럼 쿠폰 혜택 + 요리 비유 문구로 표시되며, 요리 키워드 매칭으로 음식 아이콘(🍛/🍲)도 정상 노출
- 백엔드 도메인 로직(재료 적립 → 재료조합 리워드 교환)은 변경 없이 정상 동작

## 비고

- 로컬 DB에는 이전 세션들에서 누적된 다수의 테스트 미션(FE-07/FE-09/FE-11/QA 접두사, 일부 인코딩 깨짐)이 종료(ENDED) 상태로 남아 있습니다. 고객 화면에는 노출되지 않으나 관리자 목록에는 표시되므로, 필요 시 정리를 권장합니다.
